# AivibeBoard

Фронтенд-прототип рабочего пространства с AI. Задачи и демо-проекты живут в сессии браузера; вход и регистрация — через Supabase Auth. Создание досок на странице «Мои доски» сохраняется в Supabase; правка и удаление досок пока только в интерфейсе (без записи в БД).

Без сессии открывается только страница входа. Интерфейс на русском и английском: переключатель RU | EN в шапке и на экране входа. Как устроен код — в `docs/session.md`.

Скопируйте `.env.example` в `.env.local` и заполните адрес проекта и publishable key. Файл `.env.local` в git не входит.

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Схема досок в Supabase: `supabase/migrations/20261109170336_create_boards.sql`. Примените миграции в своём проекте Supabase (CLI `supabase db push` или SQL из файла в панели).
