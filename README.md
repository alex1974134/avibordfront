# AivibeBoard

Фронтенд-прототип рабочего пространства с AI. Бэкенда нет: доска живёт в сессии браузера, вход сохраняется локально.

Без авторизации открывается только страница входа. Для демо-участников пароль `aivibe`, например `alex@aivibe.io`. Подробности — в `docs/session.md`.

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```
