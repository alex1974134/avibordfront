# Что сделано в сессии

Дата: 2 ноября 2026. Репозиторий: https://github.com/alex1974134/avibordfront

В этой сессии собран фронтенд-прототип AivibeBoard, интерфейс переведён на русский и код отправлен в отдельный GitHub-репозиторий. Бэкенда, базы данных, внешней авторизации и настоящей AI-модели нет: все данные демо-данные в браузере.

## Продукт

AivibeBoard — рабочее пространство для проектов, задач и знаний команды. Обзор собран полностью. Остальные разделы — рабочие страницы с фильтрами и действиями, а не пустые заглушки.

Два демо-пространства: Aivibe Studio (тариф Pro) и Northwind Labs (тариф «Команда»). Состояние живёт в Zustand и сбрасывается при полной перезагрузке страницы.

## Стек

- React 19, TypeScript, Vite 8
- Tailwind CSS 4 через `@tailwindcss/vite`
- React Router 7
- Zustand 5
- Lucide React, Framer Motion, шрифт Inter Variable
- `tailwind-merge` для классов кнопок, чтобы `hidden` не конфликтовал с базовым `inline-flex`

Ограничения сборки: `verbatimModuleSyntax` (импорт типов через `import type`), `erasableSyntaxOnly` (без enum), без `any`. Проверка: `npm run build` (`tsc -b` и `vite build`) проходит.

## Структура

```
src/
  app/          маршруты и корень приложения
  components/   layout и UI-кит
  pages/        страницы разделов
  features/     задачи, обзор, AI, команда, база знаний, Telegram
  data/         демо-данные
  store/        состояние сессии
  hooks/        данные текущего пространства, закрытие по клику снаружи
  types/        Project, Task, User, Activity и остальные модели
  utils/        подписи, даты, поиск, статистика, локальный черновик AI
```

## Маршруты

| Путь | Раздел |
| --- | --- |
| `/dashboard` | Обзор |
| `/tasks` | Мои задачи |
| `/projects` | Проекты |
| `/team` | Команда |
| `/knowledge-base` | База знаний |
| `/ai` | AI-помощник |
| `/ai/generator` | Генератор задач |
| `/integrations` | Интеграция Telegram |
| `/settings` | Настройки |

`/` и неизвестный адрес ведут на `/dashboard`.

## Что умеет интерфейс

- Боковая панель около 250px: логотип, переключатель пространства, разделы, блок AI, Telegram, настройки и профиль. На узком экране панель открывается как выдвижное меню.
- Шапка: название раздела, хлебные крошки, поиск, «Новая задача», уведомления, аватар. Поиск фокусируется по Ctrl+K.
- Обзор: приветствие, счётчики, карточки проектов, свои задачи, блок AI и лента активности.
- Создание задачи, смена статуса, фильтры задач и проектов, приглашение участника, правка профиля, переключатели уведомлений.
- Поиск по проектам и задачам текущего пространства.
- База знаний: категории, поиск, перетаскивание файлов. Файлы остаются только в сессии.
- Telegram: подключение имитируется, демо-адрес можно скопировать.
- AI: локальный черновик по тексту запроса, пауза 700 мс, без сетевого вызова. Ключевые слова на русском и английском выбирают тему (дизайн, маркетинг, интеграция). Задачи можно добавить на доску выбранного проекта.

## Русский интерфейс

Переведены меню, страницы, формы, пустые состояния, тосты, статусы, приоритеты, сроки, относительное время, демо-проекты, задачи, активность, уведомления и документы.

Оставлены как есть: название AivibeBoard, имена людей, адреса маршрутов, имена в коде и английские значения типов вроде категории документа. На экране категории показываются по-русски: Продукт, Разработка, Дизайн, Исследования.

Даты форматируются локалью `ru-RU`. Для счётчиков используется склонение: задача / задачи / задач и аналогичные формы.

## Git

Папка проекта лежит внутри другого репозитория (`webcode1`). Для AivibeBoard создан собственный `.git`, чтобы код не смешался с соседними проектами.

- Remote: `origin` → https://github.com/alex1974134/avibordfront.git
- Ветка: `main`
- Первый коммит: фронтенд-прототип

`node_modules` и `dist` в репозиторий не входят.
